# Code2Vault Public Template

Plantilla para conectar repos públicos con mi sistema Code2Vault AI.

## Uso

1. Crea un repo nuevo usando esta plantilla.
2. Configura los 2 Secrets en el repo nuevo:
   - `APP_ID` → (mismo valor que en otros repos)
   - `APP_PRIVATE_KEY` → (mismo valor que en otros repos)
3. Instala la App Code2Vault Bridge en ese repo (Settings → Installations).
4. Empieza a hacer push a `src/` → el sistema procesará automáticamente.
